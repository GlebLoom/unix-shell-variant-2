## Этап 1

Консольный интерфейс на Python 3.10+. Приглашение показывает имя
пользователя и компьютера. Ввод делится по пробелам. Команды `ls` и
`cd` пока работают как заглушки; `exit` завершает программу.
Неизвестная команда выводит ошибку.

Запуск: `./run.sh`.
Тесты: `python3 -m unittest discover -s tests -v`.

## Этап 2

Добавлены параметры `--vfs DIRECTORY`, `--prompt TEXT` и `--script FILE`.
Стартовый скрипт показывает команды и их результаты, продолжает работу
после ошибок. Настройки выводятся при запуске.

Пример: `./run.sh --prompt "student> " --script examples/stage2.txt`.

## Этап 3

Директория из `--vfs` загружается в память. Файлы на диске не меняются.
По умолчанию используется `examples/vfs/deep`. Неверный путь или ссылка
в исходном дереве вызывают ошибку. `ls` и `cd` пока остаются заглушками.

Проверка: `./scripts/check_vfs.sh`.

## Этап 4

Команды `ls` и `cd` работают с виртуальной файловой системой.
Добавлены `tail [-n N] FILE`, `wc [-lwmc] FILE` и `history [N]`.
История команд хранится в памяти до завершения сеанса.

Пример: `./run.sh --vfs examples/vfs/deep --script examples/stage4.txt`.
