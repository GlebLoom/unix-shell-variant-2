## Цель

Разработать консольный эмулятор оболочки UNIX и реализовать работу
с виртуальной файловой системой (VFS).

## Что сделано

Программа написана на Python. Она загружает папку с диска в память
и выполняет команды над её копией. Изменения не сохраняются на диск.

Выполнены пять этапов: ввод команд, настройки запуска, загрузка VFS,
основные команды, удаление и перемещение файлов. Каждый этап сохранён
отдельным коммитом. Историю можно посмотреть через `git log --oneline`.

## Запуск

Нужен Python 3.10 или новее. Устанавливать библиотеки и собирать проект
не требуется. Из папки проекта на macOS или Linux:

```sh
./run.sh
```

Или напрямую: `python3 -m src.main`. На Windows: `py -3 -m src.main`.
Запуск на Windows отдельно не проверялся.

Параметры:

- `--vfs DIRECTORY` — исходная папка; по умолчанию `examples/vfs/deep`.
- `--prompt TEXT` — текст приглашения. Без параметра используются
  реальные имя пользователя, имя компьютера и путь внутри VFS.
- `--script FILE` — стартовый скрипт в UTF-8.
- `--help` — справка по запуску.

```sh
./run.sh --vfs examples/vfs/deep --prompt 'gleb> ' --script examples/demo.txt
```

При запуске программа выводит настройки. `run.sh` отсчитывает
относительные пути от папки проекта. Другой интерпретатор можно выбрать
через `PYTHON=python3.12 ./run.sh`.

## Команды

| Команда | Что делает |
| --- | --- |
| `ls [-a] [PATH]` | Показывает файлы; `-a` включает скрытые имена |
| `cd [PATH]` | Меняет папку; без пути — корень VFS, `-` — предыдущая папка |
| `tail [-n N] FILE` | Выводит последние N строк, по умолчанию 10; `+N` — начиная с N-й |
| `wc [-lwmc] FILE` | Считает переводы строк, слова, символы и байты; по умолчанию `-lwc` |
| `history [N]` | Выводит всю историю или последние N команд |
| `rm [-rR] [-f] PATH` | Удаляет файл; `-r`/`-R` — папку с содержимым, `-f` допускает отсутствие пути |
| `mv [-f \| -n] SRC DST` | Переносит или переименовывает объект; `-n` запрещает замену, `-f` разрешает |
| `exit` | Завершает работу |

Опции можно объединять: `wc -lw FILE`, `rm -rf DIR`.
`--` завершает разбор опций, например `rm -- -file`.
Команды работают с одним путём; `mv` — с одной парой путей.

Ввод разделяется по пробелам. Кавычки, переменные, конвейеры
и комментарии внутри эмулятора не поддерживаются. Пути `/`, `.` и `..`
работают внутри VFS. Выйти выше виртуального корня нельзя.

Стартовый скрипт показывает команды и их результат. После ошибки
он переходит к следующей строке. `exit` завершает сеанс; без него
после скрипта можно вводить команды вручную. Ctrl+D завершает ввод,
Ctrl+C отменяет вводимую строку.

`tail` и подсчёт слов/символов в `wc` требуют UTF-8. `wc -l` считает
только переводы строки LF, `wc -c` — байты. Порядок счётчиков: l, w, m, c.
Последняя строка без LF не увеличивает значение `wc -l`.
История включает ошибочные команды и хранится до закрытия программы.

`mv` переносит объект внутрь существующей папки назначения.
По умолчанию существующий файл заменяется; `-n` оставляет его как есть.
Папка заменяет только пустую папку. Перенос в себя запрещён.
`rm` не удаляет корень, текущую папку и её родителей, даже с `-rf`.
Ссылки и специальные файлы при загрузке VFS не поддерживаются.

## Код программы

- `src/main.py`: `parse_config` читает настройки, `run_line` выводит
  результат или ошибку, `run_script` выполняет скрипт, `repl` читает
  команды, `main` запускает программу.
- `src/shell.py`: `Shell` хранит сеанс, `prompt` создаёт приглашение,
  `execute` выбирает команду. Методы `ls`, `cd`, `tail`, `wc`,
  `show_history`, `rm`, `mv`, `exit` выполняют команды.
  `_moved_path` обновляет путь сеанса после перемещения папки.
- `src/vfs.py`: `from_directory` и `_load` загружают папку;
  `resolve` и `require_directory` проверяют пути; `children`, `read`,
  `subtree` читают данные; `remove` и `move` меняют VFS в памяти.
  `_move_target` и `_check_replacement` проверяют перенос.
  `MissingPath` обозначает ошибку отсутствующего пути.
- `src/options.py`: `CommandParser` разбирает опции, `error` сообщает
  об ошибке, `nonnegative` проверяет числовые аргументы.

В `examples/vfs` находятся три примера: один файл, несколько файлов
и дерево с тремя уровнями папок. В `examples` также лежат скрипты
для демонстрации этапов. Все функции Python описаны в docstring.

## Пример работы

Часть вывода после запуска `examples/demo.txt`:

```text
gleb> cd /docs/course/topic
gleb> tail -n 2 notes.txt
line 11
line 12
gleb> wc -lwc notes.txt
12 24 96 notes.txt
gleb> cd /
gleb> mv /sandbox/move.txt /sandbox/renamed.txt
gleb> tail /sandbox/renamed.txt
Move this file in memory.
gleb> rm /sandbox/delete.txt
gleb> ls /sandbox
renamed.txt
```

После повторного запуска исходные файлы снова доступны:
удаление и переименование были выполнены только в памяти.

## Проверка

```sh
python3 -m unittest discover -s tests -v
./scripts/check_all.sh
```

Тесты находятся в `tests`. В `scripts` есть отдельные проверки настроек
и загрузки VFS. Функция `expect_status` в `common.sh` проверяет код выхода.
Коды: 0 — успех, 1 — ошибка команды или входного файла, 2 — ошибка опций
запуска. Сценарии `stage2.txt`–`stage5.txt` содержат намеренные ошибки
и возвращают 1; `demo.txt` возвращает 0.
